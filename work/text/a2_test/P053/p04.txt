3.1.3 Multi-granularity Compression
In addition to encoding useful information, the
compressor must also learn hierarchical informa-
tion organization. We define granularity b as the
starting position of an embedding sequence. The
compressed sequence should exhibit varying in-
formation densities across subsequences truncated

The adaptive selector S dynamically controls de-
coder input by progressively accumulating and ver-
ifying context embeddings during inference. The
query is encoded into a query embedding sequence
Eq = Dembed(q), while the context embedding
sequence is obtained by concatenating all com-
pressed document sequences in retrieval order:
Ec = Concat(E1, . . . , Ek). The selector iterates
through granularity levels from the inference gran-

3.2.1 Training Data Synthesis
The selector S is trained on synthesized decision
tuples. Given an instruction I, context C, and gold
response R, for each granularity b ∈ B, the hidden
states Hb and generated responses Rb are obtained
through inference with the decoder, while the label
yb is derived by evaluating Rb against R:
Hb = D(I, E1:b c )
Rb = Dgen(I, E1:b c )
yb = eval(R, Rb)
(9)
The training data xi consists of pairs:
xi = {(Hb, yb) | ∀b ∈ B} (10)
A fixed decoder requires only a unified selector, as
the generation mode remains the same.
