We first present the results of all GraphRAG instances across various
metrics and analyze key observations.17
a) Reasoning Performance. As shown in Figure 2, the reasoning
performance of different GraphRAG instances across four datasets
follows a consistent trend. With the increase in reasoning model
size and capabilities (i.e., from 7B LLMs to 72B LLMs), all instances
show significant performance improvements. Next, we analyze the
instances according to the groups defined in Table 2.
⁓⁓⁓⁓⁓⁓⁓⁓⁓⁓⁓⁓⁓⁓⁓⁓⁓⁓⁓⁓⁓⁓⁓⁓⁓⁓⁓⁓⁓⁓⁓⁓⁓⁓⁓⁓⁓a).1 Structural Methods on Both Modules (Group (I)). Instance
