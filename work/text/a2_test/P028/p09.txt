4.1.3. Experiment 3: Investigating the impact of using a disambiguating questions on retrieval results  
As mentioned in Section 3.1.2 and shown in Table 1, some questions in the ARCD dataset can only be understood 
in the context of the preceding question. Section 3.1.2 also detailed how these questions were automatically 
disambiguated using GPT-3.5 Turbo and subsequently reviewed manually, with both versions being retained. This 
section presents the results of repeating the experiment described in Section 4.1.1, with both versions of the 
disambiguated questions. The purpose of this step was to evaluate the performance of the embedding models 
independently of the ambiguity issue. The outcomes are displayed in Tables 6 and 7, respectively. Values that went 
down or did not change are marked. All other values went up.
