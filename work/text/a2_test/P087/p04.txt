3.2 Phase II: Inference-Time Reasoning via
NLI-Guided MCTS
While MMKP optimizes the input context, it does
not guarantee that the generated answer is faith-
ful. To address hallucinations, we introduce a Test-
Time Compute strategy modeled as a Markov De-
cision Process (MDP) solved via Monte Carlo Tree
Search.
