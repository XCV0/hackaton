H Technical Reproducibility Details
For reproducibility, we report the experimental
setup. HalluGuard was fine-tuned for 16 hours on
a single NVIDIA H100 PCIe GPU (80GB memory,
TDP 350W). Training consumed approximately
7.35 kWh, estimated using the Machine Learning
Impact Calculator (MLIC) (Lacoste et al., 2019).
Experiments were conducted on a Linux server
with CUDA 12.4.1 and PyTorch 2.4.0, using de-
fault random seeds and settings.
