A ORPO Objective Function
The objective function consists of the following
two components:
1. Supervised Fine-Tuning loss:
LSFT = − 1 m m∑ k=1 |V |∑ i=1 y(k) i log ( p(k) i )
2. Odds Ratio loss:
LOR = − log σ
(
log oddsθ(yw|x) oddsθ(yl|x) )
where σ is the sigmoid function.
Therefore, LORPO = LSFT + λLOR, where λ con-
trols the pretrained language model to adapt to the
specific subset of desired output and discourages
the generation of the rejected answers. Log odds
ratio loss is wrapped in the sigmoid function so
that it can be minimized by increasing the log odds
between yw and yl.
