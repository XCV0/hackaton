• Pointwise Verbalized Selection (PVS 𝑤𝑖𝑡ℎ𝑜𝑢𝑡 A): Each passage
𝑑𝑖 ∈ D is independently evaluated with a binary prompt for
utility.
• Listwise Verbalized Selection (LVS 𝑤𝑖𝑡ℎ𝑜𝑢𝑡 A): The full candidate
set D is presented, and the LLM selects the subset of useful
passages.
• Pointwise Verbalized Selection with pseudo-answer (PVS 𝑤𝑖𝑡ℎ
A): Each passage is judged individually, with reference to a
pseudo-answer.
• Listwise Verbalized Selection with pseudo-answer (LVS 𝑤𝑖𝑡ℎ A):
The entire set is presented, and the LLM selects useful passages
with reference to a pseudo-answer.
Utility-Based Ranking Methods. These methods rank pas-
sages by their estimated utility. Approaches include:
• Listwise Verbalized Ranking [53] (LVR 𝑤𝑖𝑡ℎ𝑜𝑢𝑡 A): The LLM pro-
duces an explicit ranking of passages, without a pseudo-answer.
• Listwise Verbalized Ranking with pseudo-answer [53] (LVR 𝑤𝑖𝑡ℎ
A): The LLM produces an explicit ranking with reference to a
pseudo-answer.
• Attention-based Utility Ranking (AttR) [10]: Passage utility is
inferred from the LLM’s attention weights during answer gener-
ation and normalized.
• Likelihood-based Utility Ranking (Likelihood) [35]: Utility is
quantified by the conditional probability of generating the pseudo-
answer given each passage, i.e.,𝑃(𝑎|𝑞,𝑑𝑖).
