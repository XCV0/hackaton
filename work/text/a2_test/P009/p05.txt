3.2.2. Information Organization
The LLM estimates three components for each
topic candidate tj : a summary, related key-
words, and overarching topic categories {ctj ,l}l.
These estimated components are structured as
key–value pairs, as shown in Table 2. To prevent
duplication with the previously estimated category
set C, PT-RAG calculates the cosine similarity be-
tween C ′ and C. If the similarity meets or exceeds
a predeﬁned threshold α, the system does not up-
date C, as tj can be associated with existing cate-
gories. Otherwise, any new categories are added
to the category set. These processes are deﬁned
as the function fC in Equation (2). Each new can-
didate is represented as a key–value structure,
where cl serves as the key, and the correspond-
ing value consists of the key–value pairs deﬁned
in Table 2.
Figure 3 shows an example of this estima-
tion process. The LLM ﬁrst summarizes the
conversation with the user about domestic trips,
then identiﬁes three keywordsʕ”hot springs,” ”lo-
cal foods,” and ”relaxation”ʕand assigns two topic
categories: ”travel” and ”domestic trips.”
3.2.3. Interest and Knowledge Estimation
The user’s interests In are estimated from the his-
tory of the n-th conversation hn. Speciﬁcally, topic
categories {cl}l and keywords are estimated from
hn, using the same method described in Section
3.2.2. The LLM then identiﬁes categories and key-
words that reﬂect the user’s interest among those
estimated. These selected elements are repre-
sented as im,n ∈ In. If In−1 exists, each im,n−1
is compared with each im,n. When their cosine
similarity exceeds the threshold, α, the two are
merged; otherwise, the new im,n are added to
In−1. These processes are deﬁned as the func-
tion fI in Equation (3).
