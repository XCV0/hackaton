Prompt: Initial Utterance Generation 
# Instruction
Initiate a conversation with the user according
to the following conditions.
# Conditions
- The ''Topic'' below is a piece of information
that likely contains new and interesting
details for the user. Use this topic when
speaking with the user.
- Assume that the user is not aware of the
information you are providing.
- Ensure that the content of your conversation
adheres strictly to the details in the
''Topic.'' Avoid creating fictional statements
like ''new information emerged.''
- If there is no Topic available, pose
questions related to the user's information. Do
not mention that there is no topic.

Prompt: Interest Scoring (1-10) 
# Instruction:
Evaluate the text labeled ''Evaluation Target''
based on the following conditions.
# Conditions:
- Assess whether the information is of interest
to the individual described in ''User
Information.''
- If the information is highly interesting to
the individual, assign a score of 10; if it is
not at all interesting, assign a score of 1.
Record the result under the title ''Score''
after a line break.
- If the information in the evaluation target
is relevant to the individual's interests, add
points even if it does not directly relate to
the user information.
- If any element aligns with the user
information, add points without deducting for
the non-alignment of other elements.
- Only deduct points if the information clearly
does not align with the individual's interests.
- Do not deduct points for information where
interest cannot be determined.
- Evaluate and score as objectively as
possible.
- Provide the reasoning for the score under the
title ''Reason'' after a line break.
- Write the reason without adding additional
line breaks.
- Output the ''Reason'' first, followed by the
''Score.''
# Evaluation Target:
{generated}
# User Information:
{persona}
