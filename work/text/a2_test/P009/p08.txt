4.2. RQ2: Can Topic-Initiator stimulate
user willingness to converse?
To evaluate the effectiveness of Topic-Initiator, we
performed a human evaluation using a chatbot
system built upon the proposed framework.
4.2.1. Implementation
We implemented the chatbot using ChatGPT-4o-
mini as the underlying LLM. The system con-
sists of four modules:(1) Information Gathering,
(2) PT-RAG, (3) Initial Utterance Generation, and
(4) Next Utterance Generation. Modules (1)-(3)
follow the procedures described in Section 3.
During the Information Gathering phase, the
chatbot generates three search queries based on
the previous conversation content with the target
user. The queries are generated by ChatGPT-4o-
mini, as detailed in Appendix A.1. It then conducts
web searches related to the user’s interests using
the Custom Search JSON API6 and obtains raw
texts from the web page accessed via the search
result URLs. The API parameters are conﬁgured
to retrieve up to 10 documents published within
the past seven days, in order to restrict the search
results to recent documents. These documents
via the API was temporarily referenced only during
this evaluation and was discarded after the ses-
sions.
In the PT-RAG phase, the chatbot organizes
both the retrieved web data and the conversa-
tion content into topic categories. Unlike the stan-
dard process described in Section 3.2.2, the web
search results bypass the estimation step: the
same categories and keywords as those used to
generate the search queries (i.e., derived from
the conversation content) are reused. The search
snippet is used as the value for the key ”summary,”
6https://developers.google.com/custom-
search/v1/overview
while the corresponding webpage text is used as
the value for key ”detail.” For information retrieval
in PT-RAG, we used the prompts shown in Ap-
pendix A.2.2.
The Next Generation Utterance module gener-
ates replies based on all past conversation histo-
ries, utilizing the llama-index to reﬂect past user
interactions.
At the beginning of the interaction (the ﬁrst con-
versation), the chatbot waits for user input be-
cause no user knowledge and topic candidates
are available. In subsequent conversations, it
uses PT-RAG to introduce a potentially new and
interesting topic tailored to the user’s interest and
prior knowledge. Then, the chatbot generates an
initial utterance based on the retrieved data, using
the prompt detailed in Appendix A.3.
4.2.2. Compared Methods
To examine how a chatbot’s initial utterance inﬂu-
ences a user’s willingness to converse, we com-
pared the following three methods for generating
initial utterances:
Topic-Initiator (Ours) : This method generates
an initial utterance that introduces a new and
interesting topic to the user, using PT-RAG
with the same similarity threshold parameter
(α) described in Section 4.1.3.
Proactive (no new info.) : This method follows a
proactive strategy similar to that of
Zhang et al. (2023), generating the initial
utterance based on information previously
disclosed by the user in past conversa-
tions. We used this method to investigate
whether presenting new content contributes
to stimulate willingness to converse.
Passive (baseline) : In this method, the chat-
bot only generates responses after receiving
user input. We used this method to examine
whether the chatbot’s proactive initiation itself
enhances the willingness.

ods described earlier. In the A/B test, each par-
ticipant was asked to select which chatbot they
preferred to converse with at the start of a con-
versation. Participants followed steps below:
