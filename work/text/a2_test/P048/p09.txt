and token overlap between chunks lo to 32, the number of raw
mapped triples ka and the number of hybrid retrieved chunks

entity extraction threshold, and the maximum n-gram, were
set to 0.5 and 3, respectively. Please refer to Section IV-D for

A. Effectiveness Evaluation
Based on the experiment results in Table ?? we have
observations as follow:
Firstly, in line with recent findings [31], [34], [35],
NaiveRAG [15] achieves better performance than all tested
walking-based baselines on Contextual Summarization and
Creative Generation tasks. This is because, walking-based
baselines overlook the global, and coarse-grained information
that is essential for effective summarization and creative gen-
eration. AGRAG achieves the best performance on these tasks
by providing the reasoning subgraph, as well as the hybrid re-
trieved text chunks to the LLM, offering more comprehensive
coarse to fine-grained context for query answering.
Secondly, Our AGRAG achieves the best performance on
Fact Retrieval and Complex Reasoning tasks. as it can benefit
from phrase-level dependencies by generating explicit reason-
ing chains and directly feeding it to the LLM as guidance.
Lastly, in the text classification task, HippoRAG2 [29] and
SiReRAG [71] achieve the second-best performance across
all metrics on WOS and IFS-Rel dataset respectively, outper-
formed by AGRAG. This is because text classification requires
capturing correlations between specific text entities and the
text chunks to be classified, and all of SiReRAG, HippoRAG2
and AGRAG explicitly model entity-to-passage relationships
in the KG. AGRAG achieves the best performance as its
reasoning subgraph spans multiple entity nodes in the KG and
explicitly captures the relationships between these entities and
the text chunks associated with a given classification label,
which can assist LLM classification.
