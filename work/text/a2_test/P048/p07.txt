D. Step 3: Hybrid Retrieval
Other than Graph retrieval, we also apply Hybrid Retrieval
(HR) to further enrich the context for query answering. In
Hybrid Retrieval, we retrieve the most similar text chunks THR
from all text chunks t ∈ Tc to the query’s vector representation
q, based on the hybrid retrieval score HS(·):
THR = {t ∈ Tc | t ∈ arg ⊤kr (HS(q, t))} , (20)
HS(q, t) = MS(q, t) + BM25(q, t) 2 (21)
where kr denotes the hyperparameter that controls the num-
ber of hybrid retrieved text chunks, t, q denotes the vector
representation of text chunk t and query q, respectively;
HS(q, t), BM25(q, t) and MS(q, t) denotes the hybrid retrieval
score, the BM25 [37] sparse retrieval score, and the dense
representation vectors’ cosine similarity score between query
q and text t in Equation (7).
After obtaining the textual MCMI subgraph string g and the
chunks THR from hybrid retrieval, we input them together with
the query q and the query answer generation LLM instruction
pgen, to ask the LLM to give an answer to query q based on
these provided contents.
answer = LLM(q, g, THR, pgen), (22)
