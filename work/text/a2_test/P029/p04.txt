High inter-request document overlap. Tempo-
ral analysis further shows substantial overlap in
retrieved documents among concurrently arriving
requests. As illustrated in Figure 5(b), which is
derived from the six-week trace, requests within
short time windows frequently reference identical
or highly similar knowledge chunks. This property
creates significant opportunities for content-aware
batching and high-reuse KV cache placement for
frequently accessed documents (Jie et al., 2025;
Willette et al., 2025; Yao et al., 2025b).
4 Data Source: TWEN System
The RAGPULSE trace dataset is sampled from
TWEN, a university-wide Q&A RAG system that
has served over 40,000 students and faculties since
April 2024. This section details TWEN’s system
architecture to provide context for how the trace
data was collected.
