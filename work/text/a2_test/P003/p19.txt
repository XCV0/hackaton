PROMPT TEMPLATE: MULTI-TEMPERATURE KNOWLEDGE RETRIEVAL
SYSTEM / ROLE
You are a clinical guideline assistant. Your job is to arrange candidate guideline keypoints by how
useful they are for answering the question.
INPUT
Question: <QUESTION>
Options: (A) <A> (B) <B> (C) <C> (D) <D> (E) <E>
Candidate keypoints (ID and text):
[k_1] <KEYPOINT_TEXT_1>
[k_2] <KEYPOINT_TEXT_2>
. . .
[k_N] <KEYPOINT_TEXT_N>
Temperature tag: <TEMP_TAG> (logging only)
INSTRUCTIONS
• Return a single ordered list of keypoint IDs, from most useful to least useful.
• Rank by how well each keypoint helps distinguish among options, prioritizing diagnostic criteria,
thresholds, contraindications, and treatment rules.
• Output strict JSON only following the schema below, with no extra text.
HARD RULE
Do not answer the question.
OUTPUT JSON SCHEMA
{
"version": "urgen-step1-v1",
"tau": "<TEMP_TAG>",
"ordered_keypoints": ["k_7", "k_3", "k_12", "...", "k_N"]
}

PROMPT TEMPLATE: MULTI-ANSWER AGGREGATION
SYSTEM / ROLE
You are a cautious clinical QA assistant. Answer the multiple-choice question using only the
retrieved keypoint-passage blocks below.
INPUT
Question: <QUESTION>
Options: (A) <A> (B) <B> (C) <C> (D) <D> (E) <E>
Retrieved keypoint-passage blocks (selected by ZARD, D blocks):
[k_1] Keypoint: <KP_1> Passage: <P_1>
[k_2] Keypoint: <KP_2> Passage: <P_2>
. . . (repeat until [k_D])
Temperature tag: <TEMP_TAG> (logging only)
INSTRUCTIONS
• Choose exactly one option from {A,B,C,D,E}.
• Use only keypoint-passage blocks [k_1]–[k_D]. Do not use outside medical knowledge.
• Provide a short justification in 1–2 sentences and cite keypoint IDs, e.g., [k_2], [k_5].
• If evidence is insufficient or conflicting, set insufficient_evidence=true.
• Output strict JSON only with the schema below.
OUTPUT JSON SCHEMA
{
"version": "urgen-step2-v1",
"tau": "<TEMP_TAG>",
"answer": "C",
"rationale": "...",
"evidence_used": ["k_2", "k_5"],
"insufficient_evidence": false
}
