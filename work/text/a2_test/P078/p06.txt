4.2.3 Document Entity Extraction and Document Node
Construction
We extract named entities from all documents d ∈ D to form VT
via three different strategies.
Cost-effective and LLM-free entity extraction (proposed). We
propose to apply a spaCy transformer-based NLP pipeline 1 to each
document. Named entities and noun chunks are associated with
source chunks via ϕ. All entity nodes co-occurring within the same
sentence are jointly connected as a single n-ary entity sentence
hyperedge. This pipeline requires no LLM API calls to process
document entities at index time.
LLM-based extraction (ablation). Following HyperGraphRAG
[5], we prompt an LLM for entities and triples from each chunk, at
the cost of one API call per document chunk.
Ontology augmentation (ablation). We optionally augment each
legislative VT entity’s text with domain synonyms drawn from a
hand-curated ontology before encoding, pulling entity embeddings
toward the product attribute clusters they semantically belong to.
