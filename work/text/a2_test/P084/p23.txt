Table 24: Summarized prompt templates for zero-shot
prompting based on Cognitive Appraisal Theory.
System Instruction
You are an expert Clinical Psychologist AI specialized in
Cognitive Appraisal Theory (Lazarus & Scherer). Analyze
text to generate a dense, single narrative paragraph connecting
the event, cognitive evaluation, and emotional outcome. No
lists or JSON.
Condition 1: Patient Input
Analyze the patient’s statement and write a single-paragraph
clinical formulation focusing on:
1. Trigger: The objective event.
2. Primary Appraisal: Threats to core goals or values.
3. Secondary Appraisal: Accountability (blame) and coping
potential.
4. Emotion: The specific resulting emotion.
Format: Start with "The patient appraises the situation..."
Condition 2: Therapist Input
Reverse-engineer the patient’s underlying appraisal state from
the therapist’s response. Do not summarize the advice. Infer:
1. Trigger: The presumed event.
2. Primary Appraisal: Threatened goals or values.
3. Secondary Appraisal: Limited coping potential or blame.
4. Emotion: The specific resulting emotion.
Format: Start with "The patient is likely struggling with..."
Table 25: Summarized prompt template for generating
hypothetical CBT therapist responses.
System Instruction
You are an empathetic CBT therapist. Generate a hypothetical,
ideal response to the patient’s query and supporter’s response
to serve as a search for a Vector DB. Mimic the vocabulary,
tone, and pacing of real therapists.
Prompt Template
Write a realistic, compassionate, one-paragraph therapist re-
sponse to the patient’s statement, integrating:
1. Normalization: Validate their feelings as common and
understandable.
2. Uncovering Core Fear: Identify the underlying cognitive
distortion or unexpressed fear.
3. Therapy Structuring: Explain how CBT practically tack-
les this (e.g., breaking down steps, exploring evidence).
4. Reassurance: Provide a grounded, hopeful closing.
Constraints:
- Write exactly ONE cohesive paragraph.
- Tone: Warm, validating, practical, conversational.
- Vocabulary: "explore", "prioritize", "manageable", "navi-
gate", etc.
- No AI disclaimers; jump directly into the response.
