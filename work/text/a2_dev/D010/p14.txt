4.4 Ablation study
We conduct an ablation study to evaluate the contribution of different input
features to the router’s performance on the MIRAGE and FeB4RAG bench-
marks. Specifically, we train the router to predict relevance using the following
combinations of features: (i) the query embedding and the centroid, (ii) the
query embedding and the source-id, and (iii) all three features (Section 3.3).
The query embedding must always be present as an input feature to be able
to predict relevance for that query. Table 2 summarizes the results. The model
trained with all three features achieves the highest recall on both the MIRAGE
and FeB4RAG benchmarks, indicating that both the centroid and the source-id
are important for effective routing. We also explored additional features such as
the number of documents per source and the density around the centroid. How-
ever, including these features did not lead to further performance improvements.
