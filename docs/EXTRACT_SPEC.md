# Инструкция извлечения (область 1) — для прогона одной статьи
Вход: `work/text/<a1_dev|a1_test>/<ID>/pNN.txt` (текст по страницам) + при необходимости сам PDF.
Выход: 7 CSV-строк-блоков в `out/<run>/` по схеме `docs/passport_area1.json` (и `submission_template/README.md`).
Правила: пустая ячейка = в статье нет; ничего не угадывать; `source_page` — номер страницы PDF с 1;
`source_fragment` — дословная цитата с этой страницы (проверяется `check_submission.py`);
повтор значения -> отдельная строка с `duplicate_of`; значения из чужих работ -> `result_origin=cited`;
прямой/обратный ход — разные measurements; PCE/FF в %, Voc в В, Jsc в мА/см², толщины в нм.
Статья вне области (тандем, расчёт без прибора) -> `in_scope=false` + `exclusion_reason`, других строк нет.
После извлечения: `tools/validate.py` (замечания), затем `check_submission.py`.

## Обязательно (по итогам пилота)
- Во ВСЕХ 7 таблицах колонка `publication_id` заполнена ID статьи (например `D005`), не пустая.
- Пиши CSV через модуль csv (кавычки, переводы строк), заголовок — ровно как в submission_template.
- Свой временный код держи в /tmp-подпапке с ID статьи, не в общем scratchpad (агенты работают параллельно).
- Цитируемые (cited) значения из введения/обзора тоже заносятся с result_origin=cited, device_id/measurement_id пустые.
