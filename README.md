# Извлечение данных из научных публикаций (ВИНИТИ РАН · ЮФУ)

## Запуск

В активированном виртуальном окружении:

```bash
python -m pip install -r requirements.txt
python -m uvicorn app.server:app --port 8765
```

Откройте `http://localhost:8765`. В разделе «Загрузка» выберите область и загрузите PDF. Общий пайплайн извлекает структуру и значения, сверяет цитаты со страницами, нормализует единицы и применяет правила выбранной области. Результаты можно выгрузить в CSV или JSON.

## Groq для обеих областей

1. Создайте [ключ API Groq](https://console.groq.com/keys). Передайте его серверу в `GROQ_API_KEY` перед запуском или сохраните через админку в разделе «Модель и ключ». Настройка из админки хранится в `data/app.db` и имеет приоритет над переменной окружения для выбранного провайдера.
2. Выберите **Groq**, модель `openai/gpt-oss-120b` и одного воркера. Сохраните и нажмите **«Проверить подключение»**. [Квоты бесплатного API](https://console.groq.com/docs/rate-limits) зависят от модели и аккаунта.
3. Перед защитой полностью обработайте и сохраните минимум по одной статье из областей **«Тонкоплёночные солнечные элементы»** и **«RAG и поиск по документам»**. Проверьте поиск, цитату со страницей и выгрузку для обеих областей. Оставьте исходные PDF, обработанные данные и выгрузки на компьютере, с которого будете показывать проект. Поиск и просмотр уже обработанных материалов работают без доступа к модели.

## Резерв без сети

1. Установите [Ollama](https://ollama.com/download) на машину с бекендом. Заранее скачайте модель командой `ollama pull qwen3.5:4b`. Для обработки длинных фрагментов запустите Ollama с `OLLAMA_CONTEXT_LENGTH=16384` и проверьте скорость на ваших PDF до защиты. [Настройка контекста](https://docs.ollama.com/context-length)
2. В разделе «Модель и ключ» выберите **Ollama (локально)** и `qwen3.5:4b`. Нажмите **«Проверить подключение»**, затем с отключённой сетью обработайте по одному короткому PDF каждой области. Ключ для локального режима не требуется.
3. Если Groq недоступен на защите, дождитесь завершения текущей попытки, переключитесь на Ollama и в разделе «Конвейер» нажмите **«Повторить с сбоя»**. Начните показ с уже обработанных статей.

Папки: app/ — сервер и пайплайн, site/ — интерфейс, tools/ — скрипты оценки и проверки, data/ — хранилище (не в git), docs/ — паспорт данных.
