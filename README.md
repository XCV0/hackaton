# Извлечение данных из научных публикаций (ВИНИТИ РАН · ЮФУ)

Запуск сайта и сервера:

    .venv/bin/uvicorn app.server:app --port 8765     # затем http://localhost:8765

1. Раздел «Загрузка» → «Модель и ключ»: выберите DeepSeek или LM Studio, вставьте API-ключ (хранится в data/settings.json, в браузер не отдаётся). Ключ можно задать и переменной окружения DEEPSEEK_API_KEY.
2. Перетащите PDF на страницу «Загрузка». Статья пройдёт: чтение текста → структура (материалы, приборы, слои, измерения) → значения по кускам → нормализация единиц → проверка цитат по PDF → физические проверки.
3. «Скачать CSV» отдаёт 7 таблиц формата сдачи (submission.zip).

Папки: app/ — сервер и пайплайн, site/ — интерфейс, tools/ — скрипты оценки и проверки, data/ — хранилище (не в git), docs/ — паспорт данных.
